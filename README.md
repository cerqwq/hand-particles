# Hand Particles - WebGL Particle System

A hand-tracking particle effect system using WebGL. Particles respond to hand movements detected via webcam.

## Features

- Real-time hand tracking
- WebGL particle rendering
- Interactive particle effects
- Responsive design

## Tech Stack

- **Rendering:** WebGL (vanilla JavaScript)
- **Hand Tracking:** MediaPipe Hands
- **Styling:** CSS3

## Usage

Open `index.html` in a modern browser with webcam access.

## Project Structure

- `index.html` - Main HTML page
- `js/` - JavaScript modules
  - Particle system and hand tracking logic
- `style.css` - Styles
- `vendor/` - Third-party libraries
